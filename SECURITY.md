# Security Policy

## Supported versions

Security fixes are applied to the current development version and the latest
tagged release when a release exists. Older development snapshots are not
supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email the maintainer
at `tkcaccia@gmail.com` with:

- the affected version or full Git commit;
- operating system and backend;
- a minimal reproduction or proof of concept;
- the expected impact; and
- whether the report may be credited publicly.

Receipt will normally be acknowledged within seven days. The report will be
triaged, reproduced where possible, and coordinated with affected upstream
dependencies before public disclosure. Please avoid sharing restricted data,
credentials, or private system details in the report.
